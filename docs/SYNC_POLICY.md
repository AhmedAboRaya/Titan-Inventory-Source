# المزامنة

Synology هو المرجع الوحيد للرصيد المرحل. القراءة من كاش الحساب بعد دخول ناجح؛ لا رقم محلي يُقدّم كرصد رسمي أحدث من الخادم. مسودات الطلبات والجرد قابلة للحفظ محليًا دون اتصال؛ الترحيل والاعتماد والحجز النهائي Online فقط.

Outbox يحمل operation UUID، account UUID، server instance UUID، payload hash، version، status، attempts. تكرار الطلب يعطي نفس نتيجة المعاملة؛ استعمال نفس المفتاح بمحتوى مختلف تعارض. تغيير المستخدم أو السيرفر يوقف طابور الحساب القديم ولا يعيد نسبته للجديد.

الواجهة تحمي النموذج الجاري من التحديثات، وتعرض وقت آخر مزامنة وحالة Pending/Syncing/Synced/Conflict/Failed. صلاحيات الخادم تعاد قراءتها قبل الترحيل، ويلغي تعطيل الحساب الجلسات. لا وعد بإلغاء الوصول إلى نسخة كاش على جهاز منقطع فورًا. الخروج يزيل كاش الجلسة بعد إتاحة تصدير المسودات غير المرسلة دون كشف تكلفة لمستخدم جديد.

التحقق عند الفتح/الاستئناف وكل خمس ثوانٍ أثناء النشاط مع backoff وعدم تداخل. جدولة Android الخلفية هدفها نحو 15 دقيقة وتخضع للنظام. دقيقتان حد العودة للجلسة المفتوحة، دون تجاوز انتهاء/إلغاء جلسة الخادم.
